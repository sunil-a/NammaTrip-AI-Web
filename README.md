# NammaTrip AI – Karnataka Smart Travel Companion

## About the Project
NammaTrip AI is a web application that helps users discover tourist destinations across Karnataka. Users can explore destinations, enter their budget and travel preferences, and receive destination recommendations with estimated costs and a day-wise itinerary.

## Features
* Explore Karnataka tourist destinations.
* Search and filter destinations.
* Enter travel preferences and budget.
* Receive rule-based destination recommendations.
* View estimated trip costs.
* Generate a day-wise itinerary.

## Technologies Used
* Python
* Flask
* HTML
* CSS
* JavaScript
* JSON

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/sunil-a/NammaTrip-AI-Web.git
```

### 2. Open the project folder

```bash
cd NammaTrip-AI-Web
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
python app.py
```

### 5. Open the website

Visit `http://127.0.0.1:5000` in your browser.

## Current Limitations
* Destination data uses stored sample information.
* Cost estimates are illustrative, not live prices.
* Recommendations use predefined rules rather than a trained machine-learning model.
* Live travel information and booking are not implemented.

## Future Scope
* Add more verified Karnataka destinations.
* Improve personalized recommendations.
